Application-specific CRM code is in Controllers, Models, Data, Services, ViewModels, Views and the custom CSS/JavaScript files.

The initial MVC project and local Bootstrap/jQuery assets came from the official ASP.NET Core MVC template. Their original notices remain in `wwwroot/lib`.

- ASP.NET Core, Identity and EF Core: Microsoft, MIT licence. https://github.com/dotnet/aspnetcore and https://github.com/dotnet/efcore
- Bootstrap: MIT licence. https://getbootstrap.com
- jQuery, jQuery Validation and unobtrusive validation: their upstream licences apply and are retained in vendor files.
- Chart.js 4.4.9: MIT licence. https://github.com/chartjs/Chart.js/tree/v4.4.9

Identity follows Microsoft's documented framework design: https://learn.microsoft.com/en-us/aspnet/core/security/authentication/identity

Using licensed frameworks is expected in this assignment. Their code should not be claimed as original application code.
